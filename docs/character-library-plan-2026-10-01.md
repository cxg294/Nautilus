# 人物声音与立绘配置规划

用户明确需要独立管理人物声音和立绘，且同一人物的不同立绘需要分别设置位置和大小。人物性格、背景、关系、表达习惯等描写不进入本次范围。本规划已于 2026-10-01 实施。功能入口为「文案创意 → 人物声音与立绘」，以及逐字稿工坊顶部的「人物库」。实施记录、实际参数和验证见 [人物库实施记录](character-library-implementation-2026-10-01.md)。

核心结构为：一个人物绑定声音，拥有多张立绘；每张立绘分别保存自己的显示位置和大小。播放器选中一张立绘时，同时采用它的图片和布局配置。

## 需要管理的信息

| 层级 | 字段 | 用途 |
| --- | --- | --- |
| 人物识别 | 稳定 ID、名称、别名，可选分组 | 稿件角色匹配及列表查找，例如“博士”匹配“艾博士” |
| 人物声音 | 绑定的语音实验室音色、默认语速、参考音频、实际合成试听 | 同一人物的台词复用选定声音；模型等服务参数跟随绑定的音色 |
| 人物立绘集 | 立绘列表、默认立绘、现有语气到立绘的对应关系 | 支持自动选图及手动指定某张图 |
| 单张立绘 | 稳定 ID、名称、图片、可选表情或动作标签 | 区分同人物的不同素材，改名或调整布局不改变关联 ID |
| 单张立绘布局 | 水平位置、垂直位置、显示大小 | 每张图独立校准，处理人物姿势、长宽比和图片留白不同的问题 |

语气标签仅用于现有播放器选图和配音，不扩展成人物性格描述。声音复刻、设计和音色管理复用语音实验室；人物配置页负责选择、绑定与试听。

## 每张立绘独立保存布局

首版布局采用三个主要控制：横向位置、纵向位置、大小。图片保持原始宽高比，拖动缩放时不拉伸人物。

建议以舞台左上角为坐标原点，水平与垂直位置按舞台宽高比例保存，图片底部中心作为固定定位基点。大小保存为图片显示高度占舞台高度的比例，宽度按原图比例计算。这样窗口变大或变小后，立绘仍在相同的相对位置，并保持相同的相对大小。

界面可提供左下、居中、右下快捷定位，再通过拖动和数值微调。快捷定位只修改当前选中的立绘，不成为人物级、持续覆盖所有图片的规则。首版以当前 16:9 舞台为准，其他画幅不在本轮扩展。

| 同一人物的立绘 | 布局示例 | 调整目的 |
| --- | --- | --- |
| 默认站姿 | 靠左、底部对齐、正常大小 | 常规讲解 |
| 指向右侧 | 单独向左微调，稍微缩小 | 给伸出的手臂留出空间 |
| 思考半身像 | 单独设置较小显示高度，再调整纵向位置 | 避免半身图套用全身图大小后显得过大 |

表中的位置和大小只是配置示意。具体数值应在实际图片预览中确定，不按立绘名称自动猜测。

同一张图片可以建立不同立绘条目，各自使用不同布局；底层图片文件可以共用。布局属于立绘条目，不能以图片 URL 作为唯一配置键。

## 编辑方式

建议页面使用“人物列表、声音设置、立绘编辑”三部分，立绘编辑区保留足够大的舞台预览。

1. 选择人物，绑定音色并试听，设置默认语速。
2. 从缩略图列表选择一张立绘，预览其当前位置和大小。
3. 在舞台里拖动图片移动，用等比缩放手柄或大小滑块调整；旁边的横向、纵向和大小数值同步更新。
4. 显示舞台边缘、底部基线和字幕区域，帮助判断遮挡与裁切；透明留白不同的图片可分别微调。
5. 保存当前立绘。切换到其他立绘时，立即载入那张图自己的设置。
6. 提供“重置当前立绘”和“复制当前布局到指定立绘”。复制为明确操作，复制后的配置仍然相互独立。

声音设置中的参考录音与选中声音的实际合成试听分别标明。上传新立绘时可以复制默认立绘的位置和大小作为初始值，之后独立保存。

## 播放器怎样使用

先按本句手动选择或现有语气规则确定立绘条目，再用该条目的图片、位置和大小一起渲染。比如同一人物从“默认”切换到“思考”，声音仍沿用人物声音，画面加载“思考”立绘及其专属布局。

人物库提供可跨项目复用的配置。项目保存采用的声音、立绘与布局快照，本项目可以单独调整；人物库更新后，旧项目主动采用更新才改变。对本项目做局部修改，不自动写回人物库。

单句仍可指定使用哪张立绘，本轮不另增一套单句位置或大小编辑。立绘的位置与大小调整不影响现有音频，也不触发重新合成。

## 与当前代码的差异

当前工坊将人物放在统一的显示框中：距底部 4%，框宽 32%、高 66%，左右距离为 5%；图片在框中等比适应并底部居中。立绘条目目前只有 ID、名称和图片地址，缺少自己的布局。类型中的人物级 scale 也没有在这套工坊渲染中生效。

实施时需要补齐三处：

- 在每个立绘条目中保存布局，并让新建、上传、编辑、导入导出和项目保存都携带这些字段。
- 调整预览的选图逻辑，让它返回立绘条目及其布局，渲染时实际使用这些值。
- 为没有布局字段的旧项目保留原来的显示方式；首次编辑时以原显示结果初始化，避免导入后人物突然移位或变大。

旧的人物左右位置仅用来初始化缺少独立布局的立绘。已有立绘一旦保存自己的配置，人物级站位不能再次覆盖它。

## 首版验收

- 同一人物至少三张不同长宽比或留白的立绘，能分别保存位置和大小；改其中一张不影响其他张。
- 手动选图和自动按语气换图，均使用目标立绘自己的布局。
- 预览拖动、等比缩放和数值输入一致；窗口缩放后相对位置和大小稳定。
- 带透明留白、伸展手臂或半身构图的素材可独立校准，并能在字幕区域参考线下检查遮挡。
- 保存项目、重新打开、导出再导入后，各张立绘的设置一致。
- 更换立绘及修改布局不会清除已生成音频；人物声音仍可选择和试听。
- 旧项目没有布局字段时保持原显示效果；人物库更新不自动改变旧项目。

本轮规划不含性格背景等人物描写、人物关系、自动编稿、视频渲染或复杂舞台动画。

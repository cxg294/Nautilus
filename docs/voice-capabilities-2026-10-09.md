# 声音设计、现成音色与朗读设置

2026-10-09：已在本机开发服务生效。

## 使用方式

- 语音实验室「设计」可选择 CosyVoice 3.5 Flash / Plus、Audio 3.0 Flash / Plus。填写声音描述和试听台词后创建，生成的预览音频会作为该音色的已有试听保存。
- 「音色库」新增 Audio 官方现成音色：Flash 609 个（597 基础 + 12 系统），Plus 599 个（597 基础 + 2 系统），共 1208 个。可以按名称、性别、特点、用途、模型和来源筛选，生成试听或选入合成。人物库和逐字稿工坊的音色选择也可使用这些音色。
- 合成页和逐字稿工坊「单句设置」新增「停顿与指定读法」。停顿填写定位文字、出现次数和毫秒数；指定读法填写原文与读音，应用于每一处匹配。例：原文 W3C，读成“网络协议标准”；在“先想一想。”之后停顿 1500 毫秒。
- 朗读设置只影响声音，字幕仍显示原文。修改设置后，对应台词的旧音频缓存会失效，需要重新生成。旧项目没有设置时沿用原来的缓存键。

## 能力范围

用户随后反馈完整目录太难选，选择入口已收起：默认优先展示六个已试听的 Audio Flash 角色、6 个按官方声线描述挑选的试听候选，并补入最多 4 个已命名的复刻/设计声音。当前正在使用的其他音色也会保留显示。完整目录需主动打开「更多音色」，初始筛选 Audio Flash，可以再按模型、男/女声和名称缩小范围。语音实验室、人物库、工坊共用同一选择器。

音色库默认「常用声音」只显示声音、特点、模型、试听和选用；管理信息保留在「复刻与设计」和「更多音色」。1208 是按模型分别登记的目录条目，其中 597 个基础音色分别有 Flash / Plus 版本，不能理解成 1208 种完全不同的声线。候选是试听起点，不是已人工比较得出的质量排名。

这次选择入口调整通过类型检查、构建及独立 Vue 组件页面操作验证：常用列表、完整目录展开、模型/性别筛选、收起后保留所选音色。未重新克隆或调用云端合成。截图 voice-selection-ui.png 使用测试数据，正式页面仍需登录。

停顿和指定读法目前开放给复刻音色和官方基础音色。系统音色、设计音色暂不开放；页面解释原因，服务端也会在付费合成前拒绝不支持的组合。字级时间戳亦按音色能力请求，不能把所有音色视为同一种能力。

现成音色是共享目录，不提供改名或删除。目录是官方列表的本地快照，不随每次页面访问重新抓取。生成试听按正常合成计费；保存后可以直接播放已有试听。

没有批量改动已有角色、课程或云端音色，没有新增数据库迁移。音高和音量没有加入此次配置。

## 实现与兼容

模型注册表 shared/voice-models.json 开放四模型的设计能力。shared/voice-catalog.json 保存官方目录和每个音色的目标模型，GET /api/voice-lab/catalog 返回目录、已有试听和用量。目录与云端复刻列表分别加载，避免改变原有云端分页含义。现成音色合成直接使用目录绑定，不调用用户音色 query_voice。

共享的 speechControls 使用厂商无关的 pause / reading 数据结构，出站时才编译为转义后的 SSML。只允许定位停顿和读法，不能通过字段注入标签或远程音频。支持 Unicode 字符定位，拒绝缺失定位、重叠读法、重复停顿和读法内部停顿。

SSML 改变了实际朗读字数。服务端保留 displayText 和 spokenText，经原有 token / 字符索引归一化后，将时间映射回原字幕。一个缩写读成多个词时，合并为该缩写的时间范围。不能删除原有 CosyVoice / Audio 全文索引归一化逻辑。

带朗读设置的工坊台词保持整段生成，避免切分后丢失定位文字；保存、导入、导出保留配置。声音设计的模型与类型持久化，云端列表缺少设计描述时仍能识别能力。
